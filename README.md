# 星布谷地漫游指北

> 注意：数据来源于星布谷地三测，公测时可能会有变动，届时请关注插件更新

星布谷地的菜谱、花色杂交自交配方查询与反查插件

### 依赖

需要使用`pandas`来读取表格文件

### 配置

在 AstrBot 管理面板的插件配置里选择`机器人平台模式`：

| 选项 | 说明 |
| --- | --- |
| `onebot`（默认） | OneBot（NapCat 等），不渲染 Markdown，回复会自动去掉这些标记，只留文字内容 |
| `qq_official` | QQ 官方机器人，回复支持 Markdown |


### 命令：

`/菜谱`：

- 必要参数：菜名。需要输入例如`/菜谱 时鱼汤`，会返回游戏中`时鱼汤`的菜谱
- 支持模糊搜索，比如`/菜谱 花果茶`可以自动匹配`和煦花果茶`或提示其他菜品
- 也许可以搜索现实中的菜谱（？）

`/花配方`：

- 必要参数：品类或具体花名。需要输入例如`/花配方 百合`或`/花配方 紫霞百合`，前者会输出所有`百合`相关的花色配方，后者只会输出`紫霞百合`的配方
- 可选参数：花朵品质（仅在第一个参数为花朵品类时）。比如`/花配方 百合 蓝`，会输出所有`百合`相关的蓝品质花色配方。
- 支持模糊搜索，比如`白大花马齿苋`这个名字想不起来了，随便打几个字也能匹配到（）

> 花朵品质分为 `白/蓝/紫/金`

`/花组合`：

- 必要参数：花朵品类 第一个花色 第二个花色。比如`/花组合 百合 白 黄`，会输出`百合`品类中由`白色`和`黄色`组合的花色配方。
- 如果是自交，那么只填入一个花色就好了。
